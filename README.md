# 정규식 작업대

정규식을 직접 입력하거나 블록으로 조립하면서, 예시 텍스트에 어떻게 적용되는지 바로 확인하는 웹앱입니다.
JavaScript 방언과 Python 방언(Pyodide)을 지원하며, 데이터는 브라우저에만 저장됩니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # dist/ 에 정적 파일 생성
npm run preview   # 빌드 결과 확인
npm run check     # svelte-check (타입 검사)
npm test          # 파서·트리 편집 테스트
```

`base` 가 상대 경로(`./`)라서 `dist/` 를 어느 하위 경로에 올려도 동작합니다.

## 화면 구성

- **패턴 입력창**: 항상 직접 편집할 수 있습니다. 구문을 색칠하고, 오류를 바로 보여 주며, 커서가 놓인 자리의 뜻을 한국어로 설명합니다.
- **블록 도구**: 패턴을 중첩 블록으로 보여 줍니다. 팔레트에서 끌어다 놓거나, 블록을 끌어 순서를 바꾸고 그룹 안으로 넣습니다. 수량은 블록 위에 놓습니다. 접어 두어도 입력창은 그대로 쓸 수 있습니다.
- **미리보기**: 예시 텍스트를 그 자리에서 편집하며, 일치와 캡처 그룹 강조가 입력과 함께 갱신됩니다.
- 화면 폭이 1040px 이상이면 2열입니다. 왼쪽에서 식을 고치는 동안 오른쪽 결과가 항상 보입니다.

패턴 문자열이 원본이고 블록은 항상 문자열을 다시 파싱해 그립니다. 그래서 입력창과 블록 중 어느 쪽을 고쳐도 서로 어긋나지 않습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `src/lib/rx.js` | 정규식 파서, 직렬화, 트리 편집, 한국어 설명 |
| `src/lib/engine.js` | 실행 엔진: JS 워커, Python(Pyodide) 워커, 시간 초과 처리 |
| `src/lib/app.svelte.ts` | 앱 상태와 모든 동작(컴포넌트는 이 모듈만 쓴다) |
| `src/lib/motion/` | 움직임 정책(ui-motion): 토큰 CSS, Svelte transition, 끌어 놓기 고스트 |
| `src/components/` | 카드와 블록 작업대 |
| `src/sheets/` | 모달 시트(세부 설정, 프리셋 검색, 내역·백업·설정 등) |
| `public/pyodide/` | Python 엔진 파일(약 14MB, 처음 Python 을 고를 때만 내려받는다) |
| `docs/draft-v4.html` | 이식 전의 단일 HTML 초안 |

## 키보드

| 키 | 동작 |
|---|---|
| `Ctrl/⌘ + K` | 프리셋 검색 |
| `Ctrl/⌘ + Z`, `Ctrl/⌘ + Y` | 패턴 되돌리기, 다시 실행 |
| 블록에서 `←` `→` | 이웃 블록으로 이동 |
| 블록에서 `Alt + ←/→` | 블록 옮기기(끌어 놓기의 대체 수단) |
| 블록에서 `Delete` | 삭제 |
| 블록에서 `F2` 또는 `e` | 세부 설정 |
| `Shift + 클릭` | 같은 줄의 블록 범위 선택 |
| 끄는 중 `Esc` | 끌기 취소 |
